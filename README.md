# 我们的回忆

纯原生 HTML / CSS / JavaScript，包含三张本地 SVG 插画与七张真实照片，没有外部 CDN、字体或服务依赖。

## 本地预览

直接打开 `index.html` 即可体验。也可在此目录运行 `python -m http.server 4173`，浏览器打开 `http://localhost:4173`。

日期输入：`20260103`。第一个问题输入包含「学校」或「回学校」的文字，第二个问题输入包含「湘菜」或「湖南菜」的文字即可通过。照片按上传顺序依次展示，每张约 4 秒，最后显示「未完待续」。刷新页面会从第一屏重新开始。

## 修改内容

编辑 `js/main.js` 顶部的 `CONFIG` 对象，可修改起始日期、互动密码、答案关键词、照片列表及播放时长。默认起点是北京时间 2026 年 1 月 3 日零点。

真实照片在 `assets/photos/` 中，已经校正方向、压缩并去除 EXIF 元信息，未裁切构图。需要替换时直接使用相同文件名；增减照片时同步修改 `CONFIG.photos`。

场景插画在 `assets/scenes/` 中，可以独立替换，推荐保持 600:1100 的竖幅比例。

## 部署到 GitHub Pages

1. 把本目录中的所有文件上传到 GitHub 仓库根目录，确保根目录可直接看到 `index.html`，不要只上传压缩包。
2. 在仓库 Settings → Pages 中，选择从分支部署（Deploy from a branch）。
3. 选择保存这些文件的分支，目录选择 `/ (root)`，保存。
4. 等待部署完成，使用 Pages 页面给出的链接访问。网页使用相对资源路径，支持仓库子目录地址。

互动密码用于营造体验，无法保护公开网页中的照片隐私。当前交付为本地成品，尚未上传或发布。

## 兼容说明

手机竖屏优先，使用安全区域与动态视口高度。系统开启减少动态效果时会缩短过渡并关闭花海缓动。双击缩放通过触控属性抑制，保留双指缩放。设备系统时间会影响计时结果。
